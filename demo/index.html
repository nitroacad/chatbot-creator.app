How This Mini-App Works

This page represents an external customer website embedding the chatbot using our zero-framework async loader. Notice how the floating chat widget is completely isolated in its own Shadow DOM. Styles on this host page do not leak into the chat, and the chat’s custom colors, borders, and animations do not contaminate this website.
